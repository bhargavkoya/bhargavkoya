## The Real-World Challenge: Building “ShopSphere” E-commerce Platform

Imagine you’re the lead developer at a growing startup called ShopSphere. The company has secured Series A funding and needs to rebuild their existing monolithic application into a scalable, maintainable API-first platform that can support:

- 50,000+ products across multiple categories
- 10,000+ concurrent users during peak hours
- Multiple client applications (web, mobile, admin dashboard)
- Real-time inventory management
- Complex pricing rules and promotional campaigns
- Integration with third-party services (payment gateways, shipping providers)

### Non-Functional Requirements

Performance Targets:

- API response time: < 100ms for 95th percentile
- Support 1000+ concurrent requests
- 99.9% uptime (maximum 8.77 hours downtime per year)
- Database query optimization for sub-50ms responses

Security Standards:

- OWASP compliance for web application security
- Data encryption at rest and in transit
- JWT token-based authentication
- Rate limiting and DDoS protection

## Our Architecture Strategy: Clean Architecture with Modern Patterns

To meet these requirements, we’ll implement a Clean Architecture approach combined with proven design patterns that companies like Amazon and Google use in their systems.

Our solution will follow the Onion Architecture pattern with four distinct layers:

- Domain Layer (Core): Business entities and domain logic
- Application Layer: Use cases and business workflows
- Infrastructure Layer: External services and data persistence
- Presentation Layer: API controllers and DTOs

## Step 1: Setting Up the Clean Architecture Foundation

Let’s start by creating our solution structure that enforces proper dependency flow:

```bash
# Create the main solution
dotnet new sln -n ShopSphere.API

# Core layer - Contains business logic and domain models
dotnet new classlib -n ShopSphere.Domain
dotnet new classlib -n ShopSphere.Application

# Infrastructure layer - External concerns
dotnet new classlib -n ShopSphere.Infrastructure

# Presentation layer - API and web concerns
dotnet new webapi -n ShopSphere.API

# Add projects to solution
dotnet sln add ShopSphere.Domain
dotnet sln add ShopSphere.Application
dotnet sln add ShopSphere.Infrastructure
dotnet sln add ShopSphere.API

# Establish proper dependencies (dependency inversion principle)
dotnet add ShopSphere.Application reference ShopSphere.Domain
dotnet add ShopSphere.Infrastructure reference ShopSphere.Application
dotnet add ShopSphere.API reference ShopSphere.Application ShopSphere.Infrastructure
```

Why This Structure Matters: it enforces the Dependency Inversion Principle. The core business logic (Domain layer) doesn’t depend on external frameworks or databases. Instead, outer layers depend on inner layers, making our application:

- Testable: We can easily mock external dependencies
- Flexible: We can swap implementations without changing business logic
- Maintainable: Changes in one layer don’t cascade to others

## Step 2: Domain Layer, the Heart of Our Business Logic

The Domain layer contains our core business entities, value objects and domain services. Let’s define our primary entities:

```csharp
// ShopSphere.Domain/Common/BaseEntity.cs
namespace ShopSphere.Domain.Common
{
    public abstract class BaseEntity
    {
        public int Id { get; set; }
        public DateTime CreatedAt { get; set; } = DateTime.UtcNow;
        public DateTime UpdatedAt { get; set; } = DateTime.UtcNow;
        public bool IsDeleted { get; set; } = false;

        private readonly List<IDomainEvent> _domainEvents = new();
        public IReadOnlyCollection<IDomainEvent> DomainEvents => _domainEvents.AsReadOnly();

        public void AddDomainEvent(IDomainEvent eventItem)
        {
            _domainEvents.Add(eventItem);
        }

        public void RemoveDomainEvent(IDomainEvent eventItem)
        {
            _domainEvents.Remove(eventItem);
        }

        public void ClearDomainEvents()
        {
            _domainEvents.Clear();
        }
    }
}

// ShopSphere.Domain/Entities/Product.cs
namespace ShopSphere.Domain.Entities
{
    public class Product : BaseEntity
    {
        public string Name { get; private set; } = string.Empty;
        public string Description { get; private set; } = string.Empty;
        public decimal Price { get; private set; }
        public string SKU { get; private set; } = string.Empty;
        public int StockQuantity { get; private set; }
        public int CategoryId { get; private set; }
        public int BrandId { get; private set; }
        public bool IsActive { get; private set; } = true;
        public decimal Weight { get; private set; }
        public string ImageUrl { get; private set; } = string.Empty;

        // Navigation properties
        public Category Category { get; set; } = null!;
        public Brand Brand { get; set; } = null!;
        public ICollection<OrderItem> OrderItems { get; set; } = new List<OrderItem>();
        public ICollection<Review> Reviews { get; set; } = new List<Review>();

        // Factory method for creating products
        public static Product Create(string name, string description, decimal price,
            string sku, int initialStock, int categoryId, int brandId, decimal weight)
        {
            if (string.IsNullOrWhiteSpace(name))
                throw new ArgumentException("Product name cannot be empty", nameof(name));

            if (price <= 0)
                throw new ArgumentException("Product price must be greater than zero", nameof(price));

            if (string.IsNullOrWhiteSpace(sku))
                throw new ArgumentException("Product SKU cannot be empty", nameof(sku));

            var product = new Product
            {
                Name = name,
                Description = description,
                Price = price,
                SKU = sku,
                StockQuantity = initialStock,
                CategoryId = categoryId,
                BrandId = brandId,
                Weight = weight
            };

            // Domain event for product creation
            product.AddDomainEvent(new ProductCreatedEvent(product));

            return product;
        }

        // Business logic methods
        public bool IsInStock() => StockQuantity > 0 && IsActive;

        public void UpdateStock(int quantity, string reason)
        {
            if (StockQuantity + quantity < 0)
                throw new InvalidOperationException("Insufficient stock available");

            var previousStock = StockQuantity;
            StockQuantity += quantity;
            UpdatedAt = DateTime.UtcNow;

            // Domain event for stock changes
            AddDomainEvent(new StockUpdatedEvent(Id, previousStock, StockQuantity, reason));

            // Check for low stock warning
            if (StockQuantity <= 5 && StockQuantity > 0)
            {
                AddDomainEvent(new LowStockWarningEvent(Id, StockQuantity));
            }
        }

        public void UpdatePrice(decimal newPrice, string reason)
        {
            if (newPrice <= 0)
                throw new ArgumentException("Price must be greater than zero", nameof(newPrice));

            var previousPrice = Price;
            Price = newPrice;
            UpdatedAt = DateTime.UtcNow;

            AddDomainEvent(new PriceUpdatedEvent(Id, previousPrice, newPrice, reason));
        }

        public decimal CalculateAverageRating()
        {
            if (!Reviews.Any())
                return 0;

            return Reviews.Where(r => r.IsApproved).Average(r => r.Rating);
        }
    }
}
```

## Step 3: Application Layer, CQRS with MediatR

The Application layer orchestrates our business workflows using the CQRS pattern. This separation allows us to optimize reads and writes differently:

```csharp
// ShopSphere.Application/Products/Commands/CreateProduct/CreateProductCommand.cs
namespace ShopSphere.Application.Products.Commands.CreateProduct
{
    public record CreateProductCommand : IRequest<ProductDto>
    {
        public string Name { get; init; } = string.Empty;
        public string Description { get; init; } = string.Empty;
        public decimal Price { get; init; }
        public string SKU { get; init; } = string.Empty;
        public int InitialStock { get; init; }
        public int CategoryId { get; init; }
        public int BrandId { get; init; }
        public decimal Weight { get; init; }
    }

    public class CreateProductCommandHandler : IRequestHandler<CreateProductCommand, ProductDto>
    {
        private readonly IApplicationDbContext _context;
        private readonly IMapper _mapper;
        private readonly ILogger<CreateProductCommandHandler> _logger;
        private readonly IProductRepository _productRepository;

        public CreateProductCommandHandler(
            IApplicationDbContext context,
            IMapper mapper,
            ILogger<CreateProductCommandHandler> logger,
            IProductRepository productRepository)
        {
            _context = context;
            _mapper = mapper;
            _logger = logger;
            _productRepository = productRepository;
        }

        public async Task<ProductDto> Handle(CreateProductCommand request, CancellationToken cancellationToken)
        {
            _logger.LogInformation("Creating new product with SKU: {SKU}", request.SKU);

            // Business rule validation
            var existingProduct = await _productRepository.GetBySKUAsync(request.SKU);
            if (existingProduct != null)
            {
                throw new ValidationException($"Product with SKU '{request.SKU}' already exists");
            }

            // Create domain entity using factory method
            var product = Product.Create(
                request.Name,
                request.Description,
                request.Price,
                request.SKU,
                request.InitialStock,
                request.CategoryId,
                request.BrandId,
                request.Weight
            );

            // Add to context
            _context.Products.Add(product);
            await _context.SaveChangesAsync(cancellationToken);

            _logger.LogInformation("Product created successfully with ID: {ProductId}", product.Id);

            return _mapper.Map<ProductDto>(product);
        }
    }
}
```

The query side reads through a cache first, then falls back to the database with a filter specification:

```csharp
// ShopSphere.Application/Products/Queries/GetProducts/GetProductsQuery.cs
namespace ShopSphere.Application.Products.Queries.GetProducts
{
    public record GetProductsQuery : IRequest<PaginatedResult<ProductDto>>
    {
        public int PageNumber { get; init; } = 1;
        public int PageSize { get; init; } = 20;
        public string? SearchTerm { get; init; }
        public int? CategoryId { get; init; }
        public int? BrandId { get; init; }
        public decimal? MinPrice { get; init; }
        public decimal? MaxPrice { get; init; }
        public bool? InStockOnly { get; init; }
        public ProductSortBy SortBy { get; init; } = ProductSortBy.Name;
        public SortDirection SortDirection { get; init; } = SortDirection.Ascending;
    }

    public class GetProductsQueryHandler : IRequestHandler<GetProductsQuery, PaginatedResult<ProductDto>>
    {
        private readonly IProductRepository _productRepository;
        private readonly IMapper _mapper;
        private readonly ICacheService _cacheService;
        private readonly ILogger<GetProductsQueryHandler> _logger;

        public GetProductsQueryHandler(
            IProductRepository productRepository,
            IMapper mapper,
            ICacheService cacheService,
            ILogger<GetProductsQueryHandler> logger)
        {
            _productRepository = productRepository;
            _mapper = mapper;
            _cacheService = cacheService;
            _logger = logger;
        }

        public async Task<PaginatedResult<ProductDto>> Handle(GetProductsQuery request, CancellationToken cancellationToken)
        {
            var cacheKey = GenerateCacheKey(request);

            // Try to get from cache first
            var cachedResult = await _cacheService.GetAsync<PaginatedResult<ProductDto>>(cacheKey);
            if (cachedResult != null)
            {
                _logger.LogInformation("Products retrieved from cache for key: {CacheKey}", cacheKey);
                return cachedResult;
            }

            _logger.LogInformation("Fetching products from database with filters: {@Query}", request);

            // Build filter specification
            var specification = new ProductFilterSpecification(
                request.SearchTerm,
                request.CategoryId,
                request.BrandId,
                request.MinPrice,
                request.MaxPrice,
                request.InStockOnly
            );

            // Get paginated results
            var products = await _productRepository.GetPaginatedAsync(
                specification,
                request.PageNumber,
                request.PageSize,
                request.SortBy,
                request.SortDirection
            );

            var result = new PaginatedResult<ProductDto>
            {
                Items = _mapper.Map<List<ProductDto>>(products.Items),
                TotalCount = products.TotalCount,
                PageNumber = products.PageNumber,
                PageSize = products.PageSize,
                TotalPages = products.TotalPages
            };

            // Cache the result for 5 minutes
            await _cacheService.SetAsync(cacheKey, result, TimeSpan.FromMinutes(5));

            _logger.LogInformation("Retrieved {Count} products from database", result.Items.Count);

            return result;
        }

        private static string GenerateCacheKey(GetProductsQuery query)
        {
            return $"products:{query.PageNumber}:{query.PageSize}:" +
                   $"{query.SearchTerm}:{query.CategoryId}:{query.BrandId}:" +
                   $"{query.MinPrice}:{query.MaxPrice}:{query.InStockOnly}:" +
                   $"{query.SortBy}:{query.SortDirection}";
        }
    }
}
```

Order Processing with Complex Business Logic:

```csharp
// ShopSphere.Application/Orders/Commands/CreateOrder/CreateOrderCommand.cs
namespace ShopSphere.Application.Orders.Commands.CreateOrder
{
    public record CreateOrderCommand : IRequest<OrderDto>
    {
        public int UserId { get; init; }
        public string ShippingAddress { get; init; } = string.Empty;
        public string BillingAddress { get; init; } = string.Empty;
        public List<OrderItemRequest> Items { get; init; } = new();
        public string? CouponCode { get; init; }
    }

    public record OrderItemRequest
    {
        public int ProductId { get; init; }
        public int Quantity { get; init; }
    }

    public class CreateOrderCommandHandler : IRequestHandler<CreateOrderCommand, OrderDto>
    {
        // ...injected dependencies: context, repositories, inventory and coupon services,
        // mapper and logger

        public async Task<OrderDto> Handle(CreateOrderCommand request, CancellationToken cancellationToken)
        {
            _logger.LogInformation("Processing order creation for user: {UserId}", request.UserId);

            using var transaction = await _context.Database.BeginTransactionAsync(cancellationToken);

            try
            {
                // Validate user exists
                var user = await _userRepository.GetByIdAsync(request.UserId);
                if (user == null)
                    throw new NotFoundException($"User with ID {request.UserId} not found");

                // Validate and reserve inventory
                var orderItems = new List<OrderItem>();

                foreach (var itemRequest in request.Items)
                {
                    var product = await _productRepository.GetByIdAsync(itemRequest.ProductId);
                    if (product == null)
                        throw new ValidationException($"Product with ID {itemRequest.ProductId} not found");

                    if (!product.IsInStock())
                        throw new ValidationException($"Product '{product.Name}' is out of stock");

                    if (product.StockQuantity < itemRequest.Quantity)
                        throw new ValidationException($"Insufficient stock for product '{product.Name}'. Available: {product.StockQuantity}, Requested: {itemRequest.Quantity}");

                    // Reserve inventory
                    await _inventoryService.ReserveStockAsync(product.Id, itemRequest.Quantity);

                    var orderItem = new OrderItem
                    {
                        ProductId = product.Id,
                        Product = product,
                        Quantity = itemRequest.Quantity,
                        Price = product.Price,       // Capture price at time of order
                        ProductName = product.Name   // Denormalize for performance
                    };

                    orderItems.Add(orderItem);
                }

                // Create order
                var order = Order.Create(
                    request.UserId,
                    request.ShippingAddress,
                    request.BillingAddress,
                    orderItems
                );

                // Apply coupon if provided
                if (!string.IsNullOrEmpty(request.CouponCode))
                {
                    await _couponService.ApplyCouponAsync(order, request.CouponCode);
                }

                _context.Orders.Add(order);
                await _context.SaveChangesAsync(cancellationToken);

                await transaction.CommitAsync(cancellationToken);

                _logger.LogInformation("Order created successfully: {OrderNumber}", order.OrderNumber);

                return _mapper.Map<OrderDto>(order);
            }
            catch (Exception ex)
            {
                await transaction.RollbackAsync(cancellationToken);
                _logger.LogError(ex, "Failed to create order for user: {UserId}", request.UserId);
                throw;
            }
        }
    }
}
```
