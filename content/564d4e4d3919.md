- A cache is a bet that reads repeat. It pays off until the moment many readers miss together.
- Four write/read patterns exist: cache-aside, read-through, write-through, write-back. Start with cache-aside.
- Eviction decides what leaves when memory is full. LRU is the default, LFU is the alternative.
- A stampede is many callers missing the same key and all hitting the database. Fix it with single-flight loading and by serving stale values while one refresh runs.
- Never treat a failed database query as proof the cached value is wrong.

### The incident: Facebook, 23 September 2010

Facebook’s engineering team published a postmortem the day the site went down. Facebook was down or unreachable for many users for about 2.5 hours, which the post calls the worst outage in over four years.

The cause was a piece of automation. An automated system verified configuration values held in the cache. When it found one that looked invalid, it replaced it with the value from the persistent store.
